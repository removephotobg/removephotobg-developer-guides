# RemovePhotoBG Developer Guides

Practical tutorials for secure image uploads, processing pipelines and transparent PNG workflows.

Node.js 24: run `npm ci`, `npm run build`, then `npm run validate`. Production builds require the verified Pages URL in `site.json` or CI_PAGES_URL.

Content is stored as validated JSON in content/articles. Each article has a stable slug, original Markdown, description, category, tags and publication date. Public deployments include a content-hash manifest; a Git push alone is not proof of publication.
